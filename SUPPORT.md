# Support

## Lorien Web clients

If you're a client with a question about your site, get in touch the way you normally do, or through [lorienweb.com](https://lorienweb.com).

## Everyone else

- **Bug in a public repo:** open an issue using the bug report template.
- **Feature idea:** open an issue using the feature request template.
- **Security problem:** don't open an issue. Follow the [security policy](SECURITY.md).
- **Want to hire me:** [lorienweb.com](https://lorienweb.com).

I'm a one-person studio, so there are no guaranteed response times on open-source issues.
