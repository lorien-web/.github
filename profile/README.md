# Lorien Web

Lorien Web is a small, independent web design and development studio. I build sites for small businesses and nonprofits on Nuxt, Tailwind, Sanity, and Vercel.

Most of my work is for clients, so most of the repos here are private. This page covers how I build, and what I plan to open up.

## How I build

- **Stack:** Vue and Nuxt 4, Tailwind 4, Sanity for content, Vercel for hosting.
- **Accessibility:** every site targets WCAG 2.2 AA from the first component. I track what has actually been tested in each project, and I don't claim a site is "compliant" because an automated scan passed. Automated checks are necessary but not sufficient.
- **Handover:** clients own their domains, content, and accounts. Each project keeps an ownership record of where everything lives and who has access.

## Open source

I keep a Nuxt starter and an internal design system behind this work. Both are private for now. If I open either one up, it will show up here first.
